## Historia de usuario

**Como** administrador de la plataforma,  
**quiero** crear el grupo de recursos, Blob Storage, Azure SQL y el entorno de Container Apps,  
**para** disponer de la infraestructura donde se ejecutará la aplicación.

## Criterios de aceptación

- [ ] **CA1:** Dado el portal de Azure, cuando reviso rg-clouddata-dev, entonces existen Blob Storage, Azure SQL y el entorno de Container Apps.
- [ ] **CA2:** Dado el repositorio, cuando reviso infra/, entonces encuentro los comandos para recrear los recursos.
- [ ] **CA3:** Dado Cost Management, cuando reviso los presupuestos, entonces existe un presupuesto de 20 USD con alerta al 80 %.

## Tareas técnicas

- [ ] Crear grupo de recursos
- [ ] Crear cuenta de almacenamiento y contenedores raw/ y processed/
- [ ] Crear Azure SQL Database con la oferta gratuita o serverless
- [ ] Crear entorno de Container Apps
- [ ] Documentar comandos en infra/
- [ ] Documentación actualizada
