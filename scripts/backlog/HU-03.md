## Historia de usuario

**Como** docente evaluadora,  
**quiero** que la infraestructura del proyecto se cree automáticamente al desplegarlo,  
**para** no depender de la cuenta de nube del estudiante para ejecutarlo.

## Criterios de aceptación

- [ ] **CA1:** Dado `docker compose up`, cuando termina el arranque, entonces existen los dos contenedores y el volumen compartido de datos.
- [ ] **CA2:** Dado el volumen de datos, cuando reviso su contenido, entonces existen las carpetas `raw/`, `processed/` y la base `clouddata.db`.
- [ ] **CA3:** Dado el README, cuando reviso la sección de arquitectura, entonces se indica el equivalente en Azure de cada componente local.
