## Historia de usuario

**Como** docente evaluadora,  
**quiero** clonar el repositorio y levantar los dos microservicios con un solo comando,  
**para** verificar que la aplicación funciona en mi equipo sin configuraciones manuales.

## Criterios de aceptación

- [ ] **CA1:** Dado el repositorio clonado y Docker instalado, cuando ejecuto `docker compose up --build`, entonces ambos microservicios quedan funcionando en los puertos 8000 y 8001.
- [ ] **CA2:** Dado el primer arranque, cuando consulto `GET /kpi/ventas`, entonces ya veo los datos de los archivos de ejemplo de `data-samples/`.
- [ ] **CA3:** Dado que subo un archivo a `POST /upload`, cuando consulto `GET /kpi/ventas`, entonces veo los datos de ese archivo reflejados.
- [ ] **CA4:** Dado el README, cuando sigo la sección de despliegue, entonces no necesito instalar Python ni crear cuentas en la nube.
