## Historia de usuario

**Como** integrante del equipo de desarrollo,  
**quiero** que cada microservicio tenga su propia imagen Docker construida automáticamente,  
**para** desplegarlo en cualquier entorno (local o nube) sin cambios.

## Criterios de aceptación

- [ ] **CA1:** Dado un Pull Request que cambia un servicio, cuando corre GitHub Actions, entonces se ejecutan sus pruebas y se construye su imagen Docker.
- [ ] **CA2:** Dado un servicio desplegado, cuando consulto `/health`, entonces responde 200.
- [ ] **CA3:** Dado el README, cuando reviso la sección de despliegue, entonces se explica cómo llevar las mismas imágenes a Azure Container Apps (opcional).
