## Historia de usuario

**Como** gerente comercial,  
**quiero** ver las ventas totales, el ticket promedio y el total por tienda,  
**para** detectar qué tiendas necesitan apoyo.

## Criterios de aceptación

- [ ] **CA1:** Dados datos consolidados, cuando consulto GET /kpi/ventas, entonces recibo ventas totales, número de ventas y ticket promedio.
- [ ] **CA2:** Dados datos consolidados, cuando consulto GET /kpi/ventas-por-tienda, entonces las tiendas vienen ordenadas de mayor a menor venta.
- [ ] **CA3:** Dado que no hay ventas, cuando consulto el resumen, entonces el ticket promedio es 0 y no hay error.
