## Historia de usuario

**Como** analista comercial,  
**quiero** que las ventas depuradas queden en una base de datos relacional compartida,  
**para** consultarlas de forma consistente desde reportes y Power BI.

## Criterios de aceptación

- [ ] **CA1:** Dada la base `clouddata.db`, cuando reviso el esquema, entonces existen las tablas `ventas` y `cargas`.
- [ ] **CA2:** Dada una venta ya registrada, cuando se vuelve a cargar, entonces no se duplica y se informa como `ya_registradas`.
- [ ] **CA3:** Dado el Microservicio 2, cuando consulta la base, entonces lo hace en modo solo lectura.
