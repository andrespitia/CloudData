## Historia de usuario

**Como** analista comercial,  
**quiero** que las ventas depuradas queden en una base de datos relacional,  
**para** consultarlas de forma consistente desde reportes y Power BI.

## Criterios de aceptación

- [ ] **CA1:** Dado Azure SQL, cuando reviso el esquema, entonces existen las tablas ventas y cargas.
- [ ] **CA2:** Dada una venta ya registrada, cuando se vuelve a cargar, entonces no se duplica.
- [ ] **CA3:** Dado el repositorio, cuando reviso infra/, entonces encuentro el script SQL del esquema.

## Tareas técnicas

- [ ] Diseñar tablas ventas y cargas
- [ ] Crear script SQL
- [ ] Implementar inserción sin duplicados
