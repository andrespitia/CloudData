## Historia de usuario

**Como** auditor interno de la empresa,  
**quiero** que cada archivo recibido se guarde original y depurado,  
**para** poder rastrear cualquier dato del reporte hasta su origen.

## Criterios de aceptación

- [ ] **CA1:** Dado un archivo cargado, cuando reviso el almacenamiento, entonces existe una copia sin modificar en `raw/`.
- [ ] **CA2:** Dado un archivo procesado, cuando reviso el almacenamiento, entonces existe la versión depurada en `processed/`.
- [ ] **CA3:** Dado un archivo guardado, cuando reviso su nombre, entonces incluye el identificador de la carga.

## Tareas técnicas

- [ ] Guardar el archivo original en `raw/`
- [ ] Guardar el archivo depurado en `processed/`
- [ ] Configurar la carpeta base con la variable `DATA_DIR`
- [ ] Pruebas con carpetas temporales
- [ ] Documentación actualizada

## Definición de terminado (DoD)

- [ ] Código revisado mediante Pull Request
- [ ] Pruebas automáticas en verde en GitHub Actions
- [ ] Criterios de aceptación verificados
